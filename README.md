# tenth

A personal algorithmic trading research and execution platform.

## Mission

Build a disciplined, data-driven trading system that identifies opportunities, tests strategies, manages risk and learns from results.

## Principles

- Evidence over instinct
- Backtest before risking capital
- Paper trade before live trade
- Protect capital first
- Measure every decision
- Keep strategies explainable
- Never expose API keys or credentials in the repository
